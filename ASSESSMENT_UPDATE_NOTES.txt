Key changes:
- Added the missing learner-owned resume API endpoint.
- Expanded saved result response with aggregate totals and answered/unanswered counts.
- Added zoneless-compatible explicit change detection to results/report pages.
- Improved results dashboard and full report presentation.
- Displays category scores and the complete saved report text.
- Preserves selected answers in browser sessionStorage across page refreshes.
- Allows retrying submission after a network failure; server remains authoritative for deadline and scoring.

Important existing limitations identified:
- Assessment start currently calls generate_mock_questions(); assessment_ai.py is present but is not wired into the start endpoint.
- Current report generation is deterministic/rule-based (rule-based-v1), not an AI-generated or clinically validated psychometric interpretation.
- Backend report/results endpoints are learner-owned only. Admin/Teacher reporting dashboard and teacher-to-cohort assignment APIs are not implemented in this source archive.
- No migration is required for these changes; existing assessment tables are reused.
